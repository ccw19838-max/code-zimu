# Icon sources

This project embeds three shared team illustrations: `robot.svg`, `project-folder.svg`, and `history.svg`. They were generated for the robotics workspace and converted to SVG path geometry with VTracer 0.6.15; they contain no embedded raster images and need no runtime image tooling.

Original assets and concept attribution are recorded in [workbench-navigation's dev/cc icon documentation](https://github.com/ccw19838-max/workbench-navigation/blob/main/web/icons/SOURCE.md). They are bundled here as standalone visual assets.

The functional icon attribution is retained with [LICENSE-PHOSPHOR.txt](LICENSE-PHOSPHOR.txt), for Phosphor Icons 2.1.1 under the MIT license: https://github.com/phosphor-icons/core . The UI uses local inline SVG, without a CDN or icon package at runtime.
