# 本地界面字体

团队代码界面使用 IBM Plex Sans SC。正文为 Regular，标题、选中菜单与重点数据使用 Bold；不使用斜体标题。字体随 Go 程序本地提供，不访问字体 CDN。

来源：IBM 官方 `@ibm/plex-sans-sc` 1.1.0，原始完整 Regular / Bold WOFF2，未修改字体。

https://registry.npmjs.org/@ibm/plex-sans-sc/-/plex-sans-sc-1.1.0.tgz

字体采用 SIL Open Font License，原文见 [OFL.txt](OFL.txt)。
